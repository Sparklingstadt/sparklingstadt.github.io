# Sparklingstadt

Personal portfolio hosted at **https://sparklingstadt.github.io/**.

Plain HTML, CSS, and JavaScript. No build step or package installation required.

## Preview locally

```sh
python3 -m http.server 8000
```

Visit http://localhost:8000. Edit `index.html` for content, `style.css` for appearance, and `script.js` for theme preferences. Google Fonts is optional; system fonts are used when unavailable.

## Deployment

GitHub Pages serves the root of the `main` branch. Changes pushed to `main` are published automatically. `.nojekyll` disables Jekyll processing.

The site features public projects from [Sparklingstadt on GitHub](https://github.com/Sparklingstadt). Project artwork is decorative CSS typography, not application screenshots. The site has no analytics or tracking scripts; only the theme preference is stored locally.
