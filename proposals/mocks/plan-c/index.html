コードの言語 × ことばの言語

学んでいるプログラミング言語と自然言語を、似ていると感じる点で組にしています。

Go 中文

語形が変わらない簡潔さ

動詞が活用しない中国語と、機能を意図的に絞った Go。少ない規則で、語順と構造に意味を持たせる点が似ています。

Kotlin Русский

豊かな表現力

6つの格で語順を自由にするロシア語と、拡張関数や DSL で書き方の幅を広げる Kotlin。表現の自由度が高い分、読みやすさの判断が問われます。

TypeScript Čeština

精密な型

7つの格と háček で語の役割を細かく示すチェコ語と、構造的な型で値の形を示す TypeScript。形を見れば役割がわかります。

複数形を、Web標準で

プロジェクトの数を、各言語の正しい複数形で表示します。ロシア語とチェコ語は数によって語尾が変わります。判定はブラウザ標準の Intl.PluralRules に任せています。

5 
new Intl.PluralRules("ru").select(5)
// → "many"
