Proposals Sparklingstadt Standard §10

デザイン案のモック一覧

ポートフォリオのデザイン案を、実際に操作できるモックとして並べています。どれも HTML・CSS・少しの JavaScript だけで書いています。

§1 モック

§1.1 plan-b

Apple の Human Interface Guidelines に沿った案。グループ化したリストと、ダークモード・文字サイズの切り替え。

操作
ダークモード、文字を大きく、プロジェクトの絞り込み

§1.2 plan-c

多言語の案。5言語の挨拶、Intl.PluralRules による複数形、Intl.DateTimeFormat による4都市の時刻。

操作
表示言語、数の増減(ロシア語・チェコ語の複数形)

§1.3 plan-b-a-c

HIG の骨格、仕様書風の型定義カード、多言語のキャッチコピーを組み合わせた案。

操作
表示言語

§1.4 plan-hig-material3

同じ HTML を、デザイントークンの差し替えだけで HIG と Material 3 に切り替える案。

操作
デザイン、ダークモード、表示言語、プロジェクトの絞り込み

§1.5 plan-desktop-macos-arch

ページをデスクトップに見立て、macOS と Arch Linux + Hyprland のウインドウ表示を切り替える案。

操作
デスクトップの見た目

§1.6 plan-desktop

最新の案。macOS、Arch Linux + Hyprland、Material 3、HarmonyOS の4つを切り替える。

操作
デザイン、ダークモード、表示言語、プロジェクトの絞り込み

§2 注記

Note

名前・GitHub・メールアドレス、所持資格、複数のモックで共通する文言(5言語の挨拶とキャッチコピー、見出し、プロジェクト、ノート、Rice の話など)は、6つのモックすべてが共通の data.json から読み込んでいます。角括弧 [ ] の部分は仮の文字列です。モックは検索エンジンに登録されません。
