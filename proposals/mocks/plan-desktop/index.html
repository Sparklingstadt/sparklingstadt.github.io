型と言語のあいだで、Webをつくる。

Webエンジニア志望の sparklingstadt です。macOS の、おしゃれなのに実用的なデザインが好きです。Arch Linux と Hyprland で自分の環境を作り込むうちに、Linux そのものにも惹かれました。TypeScript を軸に Go と Kotlin を学び、中国語・ロシア語・チェコ語も勉強しています。
