§1 Abstract

This document defines Sparklingstadt, an aspiring web engineer. Sparklingstadt prefers implementations that follow the specifications and respect each user's environment, writes mostly TypeScript, and has a strong interest in Go and Kotlin. Sparklingstadt enjoys reading Apple's Human Interface Guidelines [HIG] and is learning Chinese, Russian, and Czech.

§2 Status of this document

This document is a Living Standard. It is updated as new projects ship and as learning progresses. Earlier versions are available in the GitHub commit history.

Note

Without JavaScript, this document is shown in English. Language and theme preferences are stored only in your browser.

§3 Conformance

The key words MUST and SHOULD in this section are to be interpreted as described in [RFC2119]. When writing code, Sparklingstadt follows these requirements.

  1. MUST Whatever can be built with web standards must be built with web standards.
  2. MUST The color scheme, motion, and text size that each user has chosen must be respected.
  3. SHOULD Types should read as documentation.
  4. SHOULD The main content should remain readable without JavaScript.

§6 Environment

Sparklingstadt likes macOS for being stylish and practical at the same time.

Building a rice on Arch Linux with Hyprland led Sparklingstadt to an interest in Linux itself.

Note

A rice is a customized desktop, built by editing configuration files such as hyprland.conf.

Example 1 
# hyprland.conf
general {
  gaps_in = 5
  gaps_out = 10
  border_size = 2
}
decoration {
  rounding = 10
}
